## 1. 做了什么

需求是"像 skipping-stone 那套 MATLAB 一样的纯 MGA"：**只有出发和到达算能量，
中途飞越全是弹道，不允许 DSM，也不允许在飞越近心点点火**。

pykep 自带的 `mga` 目标函数是

```
DVlaunch + Σ fb_dv(v∞in, v∞out, planet) + DVarrival
```

`fb_dv` 在 `|v∞in| ≠ |v∞out|` 或转角超过行星极限时，会在飞越处补一个脉冲，
染色体里也没有飞越近心半径。所以它不是纯 MGA。

`step8` 改成纯圆锥拼接：

- 决策量只有 `[t0, T1..TN]`（N 段 Lambert），飞越 `rp` 是**输出**。
- 飞越强制 `|v∞out| = |v∞in|`；转角 `δ = angle(v∞in, v∞out)`，
  `rp = μ/v∞² · (1/sin(δ/2) − 1)`。
- 可行条件 `δ ≤ δmax = 2 asin(1/(1 + rp_min·v∞²/μ))`。
- 目标 `J = w_dep|v∞dep| + w_arr|v∞arr| + W·Σ(Δv_fb)²`，
  `Δv_fb = |v∞out − R(δmax)·v∞in|`；`max Δv_fb < 1e-3 km/s` 判为可行。
- SADE 全局搜索；`--polish` 用 SLSQP 把模长差当等式约束、rp 当不等式约束精修。
- 地球-地球段的 Lambert 要**放开圈数**：TOF≈730 d 时 0 圈分支给的是
  a=1.5874 AU / 1 圈（非谐振），1 圈分支才是 a=1.0000 AU / 2 圈的 1:1 谐振解。
  `--revs` 默认 `[0,0,1,0]` 取的是前者，复现 skipping-stone 必须 `[1,1,3,1]`；
  更根本的问题是转移角≈0° 时两点 Lambert 退化，见 §8.2 / §9。

本次用两种方式找窗口：

1. 直接对 1988、1989 窗口做定向优化；
2. `--scan` 在 1984–1994 年每 90 天切一个 150 天窗，用短 DE 找种子（41 窗，
   结果在 `eveej_puremga_scan.csv`），再把低能种子做 defect-only 精修。

## 3. 文昌发射几何

用 step1 的 `build_hyperbola` + `daily_window`，把 pykep 的黄道 v∞ 先绕 x 轴
转 ε=23.4392911° 到赤道系，再算发射方位角走廊（90°~175°）内的当日窗口。
`t_launch` 是 TMI 时刻；`t_launch + coast + t_SOI ≈ departure`。

### C（1988-03-29 窗口）

```
v∞ = 4.2592 km/s   赤纬 +8.977°   R.A. 135.458°

i = 19.61453°      az = 90.037°     coast = 71.30 min
SOI 到达 1988-03-29 09:55:44（与 departure 一致）

`v∞ 赤纬 = 8.98° < 场址纬度 19.61°`，所以最小倾角由场址决定，正好 19.6145°，
方位角 90.04°——**正东发射**。

```

## 7. 注意事项

1. **行星位置用的是 pykep `jpl_lp`（低精度黄道根数）**，适合搜索窗口和相位，
   不适合直接当发射标称。最终标称要用 step6/DE421 或 GMAT 自己的高精度星历重打靶。
2. **C3 是出发 v∞ 的平方**（km²/s²），不含发射场自转和上升段损失。文昌实际
   运载能力要按火箭的 C3-载荷曲线折算；低 C3 窗口（15.7~18.1）对长征五号
   这类火箭很宽松。
3. **飞越高度下限**设的是地球/金星 300 km。若任务要求更高（例如地球飞越
   >1000 km 以避免大气），把 `--rp-min` 提高后重新优化，v∞dep 会略升。
4. **到达 v∞ 高的窗口**（A/B）木星捕获 Δv 更大；若捕获质量是硬约束，应把
   `--w-arr` 调大重新跑，或对 A/B 单独做木星捕获预算。
5. **纯 MGA 的"零脉冲"只在 patched-conic 模型内成立**。真实星历下总有
   TCM；step6 给出的 285~436 m/s 就是这笔预算的量级。

## 8. Skipping_stone 交叉验证（step9）

GitHub 仓库 `Quantum-dogdog/Skipping_stone` 打印了一条 E-V-E-E-J 轨迹
（出发 MJD2000 10928.4896 = 2029-11-16，五个历元，每次借力给 (转角 δ, Closest

| 木星到达 \|v∞\| | 6.136 km/s | 6.1356（−0.01%） | — | 复现 |

| ③ 地球1 借力 + 谐振返回 | δ=24.479°，CA=6926.2 km，TOF 730.5056 d | 22.134° / TOF 730.5132 d / a=0.999999 AU / TOF÷P=2.00000 / 残差 133 km | 钉 δ=24.479° → TOF 730.5068 d（差 +0.0012 d）/ a=0.999997 AU / 残差 1341 km / 返回历元 16:00:43 vs 打印 15:59 | **复现**（1:1 谐振） |
| ④ 地球2 借力 → 木星 | 隐含 \|v∞\|=10.822，δ=33.608° | 按打印历元需 11.0906，零脉冲只能给 10.4571 → 缺 **633 m/s** | 需 11.0370 vs 10.4636 → 缺 **573 m/s**；δ≤δmax=41.32° 内最近木星 4.31×10⁸ km | **未复现** |

⇒ 前三段（含 skipping-stone 的核心——1:1 谐振返回）在两套星历下都能用
零脉冲纯借力打出来；最后一段不行，`Total Delta-V = 0` 到地球2 之后就不成立了。

### 8.2 那一段为什么正好是 1:1 谐振

谐振返回的出射轨道 a=1.0000 AU ⇒ P=365.256 d，TOF=730.5 d = 2.0000 个周期，
近日点 q=0.7236 AU 刚好擦到金星轨道、远日点 Q=1.2764 AU。航天器回到地球时
地球也刚好回到同一位置（周期比 = 整数），这就是"打水漂"的相位条件。
|v∞|≈10.46 km/s 不是来自能量（a 固定 ⇒ 能量固定），而是来自飞行路径角——
椭圆朝向决定了相对地球的速度大小。同一谐振族里还有 3:1 等成员（TOF≈1096 d），
但打印的是 2 周期那一支。

### 8.3 病态程度：为什么不能逐位复现

打印历元只到分钟、B 面角 ψ 根本没打印，而谐振命中对这两个量极端敏感：

| 扰动 | 命中点到地心的距离 |
|---|---|
| ΔTOF +0 min | 133 km |
| ΔTOF +1 min | 1,804 km |
| ΔTOF +10 min | 17,998 km |
| Δψ +0.001° | 12,485 km |
| Δψ +0.010° | 124,834 km |

谐振命中在 TOF 空间上是**孤立点**（容差约 1 分钟），所以验证只能做到
"同族同量级"，不能要求逐位一致。

### 8.4 最后一段不可达的对称性论证

1:1 谐振返回有个硬后果：出射渐近线与入射渐近线相对地球**同模长**（零脉冲），
而且回到的是同一个位置、同一颗行星 ⇒ 地球1 出射的 |v∞| 与地球2 入射的
|v∞| 必然相等（本算 10.4572 vs 10.4571，DE421 10.4636）。打印表里两行地球
数据却隐含 10.553 与 10.822 两个不同值 → 两行不可能同时自洽。按打印历元
要到木星，地球2 需要 11.04~11.09 km/s，比谐振能给的 10.46 km/s 多 0.57~0.63 km/s。

## 9. 谐振返回模式 `--resonant`：把模型缺陷补上

§8 的验证用的是 step9 自己的打靶。这一节回答另一个问题：**step8 能不能自己
搜出前三段**。答案原本是不能，原因不在搜索，而在模型；补上谐振返回模式后能了。

### 9.1 原来为什么搜不出来

- 打印轨迹的地-地段转移角只有 **0.0071°**。两点 Lambert 在 0° 附近是**退化**的：
  过同一个点、同 a 的椭圆有无穷多条，|v∞| 由椭圆朝向（飞行路径角）决定，
  而 pykep 只返回共面切向的那几条（δ=0.00°、|v∞| 4.42/6.46/6.97 km/s 一族），
  10.46 km/s 那条根本不在候选集里 → 地球飞越缺陷怎么都压不到 0。
- 放开圈数（`--revs`）也没用：TOF 是外层随机搜的连续变量，而谐振命中在 TOF 轴上
  只有约 1 分钟宽（§8.3），落在 60 d 长的箱子里的概率约 1e-5。
- 实测：把 step9 的精确解喂给老 step8，金星段缺陷 0.00 m/s，地球段缺陷
  861.77 m/s（δ 42.69° > δmax 39.45°、高度 −432 km）。**是表达不出来，不是搜不到。**

### 9.2 改法

`--resonant LEG:K` 把第 LEG 段（从 0 计数，需要前一段给入射渐近线）从 Lambert
换成内层打靶：

- 未知量 `(δ, ψ, τ)`，方程是 τ 天后命中目标行星的 x/y/z —— 3 个方程 3 个未知量，
  用 `scipy.least_squares` 解，12 个初值（δ 取 0.25/0.5/0.75/0.95×δmax，ψ 取
  0/120/240），τ 限定在种子 ±20% 内，命中残差上限 `--res-tol`（默认 1e4 km）。
- 出射速度写成 `v_sc = v_行星 + |v∞|·u(δ,ψ)`，`u` 在以入射渐近线为轴、半顶角 δ 的
  锥面上 ⇒ **|v∞out| = |v∞in| 由构造保证**，该段缺陷恒为 0，只剩 `rp ≥ rp_min` 要查。
- `K` 是选支：所有命中解按 `(|τ/P − K|, 残差)` 排序，`K=2` 就是 1:1 谐振
  （2 个日心周期）那一族，`K=3` 是 3:1 那一族。
- 染色体里的 `T[LEG]` 降级成种子/选支提示，真正的 τ 是**输出量**；导出 JSON 的
  `meta.resonant` 记录 τ、δ、ψ、a、P、τ÷P、残差。谐振段后面那段（地球2→木星）
  的起点历元也改用解出来的 τ，到达行星状态按 `τ + T` 现取星历。
- `--polish` 在谐振模式下自动跳过（SLSQP 那套 Lambert 残差不再适用）。

### 9.7 通用性：`--resonant` 不是 E-V-E-E-J 的特调

段号、行星、圈数**全是参数**，代码里没有任何 hard-code：
内层用"该节点声明的那颗行星"的 μ / rp_min / δmax，`i ∈ 1..段数-1`（不能是第 0 段，
因为需要前一段给入射渐近线），k 只用于选支。实测：

| 场景 | 命令要点 | 内层解出 | 缺陷 |
|---|---|---|---|
| 换圈数 k=3（地-地 3:1） | `--resonant 2:3` | τ=1095.7694 d，τ/P=**3.0000**，a=0.999999 AU，残差 463.5 km | max **0.759 m/s → 严格可行** |
| 换行星 + 换腿号（金-金 3:1） | `--names earth,venus,venus,earth --resonant 1:3` | τ=674.1024 d = 3.00000×224.701 d，a=0.7233 AU | 飞越1（金星）**0.00 m/s** |
| 多段谐振 | `--resonant 1:2,3:3` | 两段各自独立求解 | 正常解码 |
| 非法声明 | `--resonant 0:2` / `4:2` / `1:0` | — | `__init__` 直接报错（段号 1..n-1、k≥1） |

第二行值得注意：金星的 3:1 返回**同样**被正确解出（τ/P=3.00000，近金 300 km 下
δmax 够用），说明谐振解法与行星无关。那次搜索的**第二个**金星节点缺陷 182.78 m/s，
是因为该返回构型本身不对称（入射/出射 \|v∞\| 由两段 Lambert 分别定），
优化器如实报告不可行——这是构型问题，不是谐振模块的问题。

**一个诚实的边界情况**：内层只在染色体那段 TOF 种子的 **±20% 窗口**里求解，k 靠命中排序选支。
同一段换个 k 不一定收敛到谐振点——同一序列改 `--resonant 1:2`（`--tof` 给 420,470 覆盖 2×224.7 d），
解出 τ=367.13 d / a=0.8797 AU / **τ/P=1.2181（目标 2 圈）**、残差 0 km：
它**打到了金星，但没落在谐振族上**。这不是崩了，而是日志会原样打印 `τ/P=…（目标 k 圈）`
来提示你"这一段没谐振"（对地球 1:1 那类低能返回，k=2/3 都能干净解到 2.00000/3.00000；
金星在高 v∞（17~23 km/s）下同行星返回要 `P_sc = P_金星`，是 TOF 空间里更尖的一个孤立点，
需要更合适的 t0/前段构型才撞得进去）。对照输出见 `data/evve_resonant_通用性.txt`。

产物：`data/evee_resonant_k3_nodes.json`、`data/evve_resonant_k3_nodes.json`、
`data/evve_resonant_通用性.txt`。

另外，`--resonant` 不声明时代码走原来的 Lambert 路径，本次改动**未触碰**该路径，
§2 的 5 个可行窗口可原样复现（回归通过）。
